# Security Policy

## Supported Versions

Only the latest major version of this package receives security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately via
[GitHub Security Advisories](https://github.com/leandrocfe/filament-ptbr-form-fields/security/advisories/new)
instead of opening a public issue.

We will acknowledge your report and aim to release a fix as soon as possible.
